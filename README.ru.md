**Наблюдайте за эволюцией, которая ищет математические формулы для числовых последовательностей.**

Задумывались ли вы, какая формула скрывается за числами `1 2 4 8 16`? 

seq2formula отвечает на этот вопрос, запуская генетический алгоритм прямо в вашем браузере. Программа скрещивает и мутирует математические выражения, в реальном времени показывая весь процесс поиска. Это не просто чёрный ящик с ответом — это увлекательное зрелище эволюции формул.

![Дашборд seq2formula](docs/img/dashboard-search.png)

Всё работает локально на вашем компьютере. Никаких подключений к интернету, телеметрии или внешних API. Только Python-движок, который ищет формулы, и удобный дашборд, который показывает результат.

## Возможности

- **Живой дашборд:** Наблюдайте за эволюцией формул в реальном времени с подробными графиками приспособленности, ошибок и разнообразия популяции.
- **Режим Автопилота:** Поставьте в очередь всю библиотеку и позвольте движку решать задачи одну за другой в фоновом режиме.
- **Продвинутая математика:** Поддержка базовой арифметики, корней, факториалов, тригонометрии (`sin`, `cos`), логарифмов и констант (π, e).
- **65 встроенных последовательностей:** Библиотека от простых линейных прогрессий до известных последовательностей вроде чисел Фибоначчи и Каталана.
- **Свои последовательности:** Введите свои числа, задайте эталонную формулу и наблюдайте за её поиском.
- **Воспроизводимость:** Введите «сид» (seed), чтобы повторить тот же самый процесс поиска, или оставьте поле пустым для случайного прогона.

## Как это работает

- **Правильность по значениям:** Движку неважно, найдёт он `2*n` или `n+n`. Если числа совпадают — формула верна.
- **Штраф за сложность:** Эволюция естественным образом отдаёт предпочтение коротким и красивым формулам. Без этого она порождала бы гигантских нечитаемых монстров, которые случайно совпадают с числами.
- **Точность:** Формула оценивается путём подстановки в неё ваших чисел (например, `n = 1, 2, 3...`). Чем ближе результат к вашей последовательности, тем выше оценка.

## Дашборд

Дашборд создан для наблюдения. На главном экране отображается лучшая текущая формула в красивой математической вёрстке, топ-5 лидеров и живая лента событий. Мини-график визуально сравнивает найденную формулу с целевой последовательностью. 
Во вкладке «Результаты» хранится история, «Зал славы» (самые короткие формулы) и «Курьёзы» (нелепые, но почти правильные решения). Поиск можно в любой момент поставить на паузу, пройти поколение за поколением или ускорить.

## Быстрый старт

Требуется Python 3.10+.

Для Windows:
```bat
git clone https://github.com/OlyoshaOlyosha/seq2formula.git
cd seq2formula
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
run.bat
```

Для Mac / Linux:
```bash
git clone https://github.com/OlyoshaOlyosha/seq2formula.git
cd seq2formula
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
chmod +x run.sh
./run.sh

## Статус и направления

Экспериментальный проект в постоянном развитии.

- Стадия 1 (готова) — эволюционный движок с «фазой усадки» после
  решения, живой дашборд, выбор доступных операций, встроенная
  библиотека загадок с нарастающей сложностью.
- Грамматика v2 (готова) — унарные функции (корни, факториал,
  тригонометрия, логарифм), оператор остатка и константы π / e; выбор
  операций разбит на «Базовые» и «Расширенные», тиры T4/T5 демонстрируют
  новые операции (всего 65 последовательностей).
- Скорость и качество поиска (готово) — вычисление формул через
  компиляцию (поколения в ~3 раза быстрее), механизмы разнообразия
  (штраф за клоны, адаптивные встряски, взвешенная сложность операций),
  перебор настроек по всей библиотеке; хроника рендерит формулы
  математической вёрсткой, любую формулу можно построить графиком рядом
  с её последовательностью.
- Стадия 2 (следующая) — движок с обучением с подкреплением: собирает
  формулу шаг за шагом и обучается вживую, на каждой загадке; обученные
  политики сохраняются, переиспользуются и сравниваются.
- Далее — рекуррентные соотношения, больше статистики, новые
  эксперименты с параметрами движков.
